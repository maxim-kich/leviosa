# Governance

**Sole maintainer:** Maxim Kich (Maxim Shevchenko-Tymchuk), GitHub `@maxim-kich`.

The maintainer sets product direction, accepts or declines contributions, merges PRs and publishes releases. There is no committee, voting process or automatic path to write access. Contributors are credited without becoming maintainers.

Bug reports and scoped proposals belong in GitHub Issues. Security reports follow [SECURITY.md](SECURITY.md). Larger work needs an agreed scope first. Decisions should be explained in the relevant issue or PR when practical.

The maintainer may defer or close work outside the project’s scope or review capacity. Forking and redistribution remain permitted by the MIT license; project policies do not narrow that license.
