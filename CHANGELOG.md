# Changelog

## 0.0.1

- Train a trackpad symbol with three examples and assign an application.
- Activate drawing with a configurable shortcut or optional inward corner swipe.
- Use multiple strokes, Enter to submit, C to clear and Escape to close.
- Create, edit, reorder and delete gestures in native settings with drawing previews.
- Keep gesture recognition and storage local.
- Include signed Sparkle updates with separate download/restart consent and safe input shutdown.

See the [0.0.1 release notes](docs/release-notes-0.0.1.md) for tested configuration and limitations.
