# Security

Report vulnerabilities through GitHub’s private vulnerability reporting once enabled for the repository. If it is unavailable, open a minimal issue requesting a private contact channel without including sensitive details. Do not post credentials, private gesture data or exploit details publicly.

LeviOsa uses an undocumented trackpad interface, pointer holding/hiding during drawing, and optional permission-gated shortcut modes. Report unintended input suppression, failure to restore input, actions affecting unrelated windows, or unexpected data transmission.

Updates require signed feeds and archives with verification before extraction. Private signing keys stay outside the repository. Review logs and screenshots before sharing them. No independent security audit or guaranteed response time is claimed.

Only tagged artifacts explicitly published as releases are distribution builds. Local and CI validation artifacts are not supported releases.
